# ThreatGraph frontend

Next.js 15 + TypeScript + Tailwind CSS + shadcn/ui, with Cytoscape.js for the threat graph and Recharts for analytics.

```powershell
npm install
npm run dev
```

The UI expects the backend API at `http://localhost:8000` (override with `NEXT_PUBLIC_API_URL` in `.env.local`).
See the [project README](../README.md) for full setup and usage.
